## 二、知识库（给你的 Agent 读）

`知识库/` 是把课件按**概念**重新组织的一座小型 Wiki，41 篇文章互相链接，每篇都标注了出自课件哪一章。

- `index.md` —— 导航地图，建议从这里开始
- `wiki/*.md` —— 41 篇概念文章（是什么 / 怎么用 / 关键细节 / 常见陷阱）
- `knowledge-graph.html` —— **双击用浏览器打开**，可视化知识图谱，点击能力域展开概念、可拖拽缩放，支持三套配色

它和课件的区别：课件按"学习顺序"讲，知识库按"概念"组织——查某个具体问题时更快。

把整个 `知识库/` 目录丢给你的 AI 助手（Claude Code、Cursor 等），它就具备了这门课的知识。

## 三、Agent Skills（给你的 Agent 用）

`Agent-Skills/` 里的 13 个技能，是把课件中的实操流程提炼成 **AI 助手能直接照着执行**的步骤。知识库让它"懂"，技能让它"会做"。

| 能力域 | 技能 |
|---|---|
| 环境与安装 | `bootstrapping-langchain-env` |
| 智能体核心 | `building-tool-calling-agent`、`extracting-structured-output` |
| 中间件 | `writing-agent-middleware`、`applying-builtin-middleware` |
| 记忆与状态 | `persisting-agent-memory`、`inspecting-checkpoint-state` |
| 人工审批 | `gating-agent-actions-with-approval` |
| 可观测 | `deploying-langfuse-selfhost`、`tracing-langchain-agent` |
| 检索增强 | `building-agentic-rag`、`grading-retrieved-documents` |
| 长程任务 | `building-long-horizon-agent` |

**在 Claude Code 中使用**：把需要的技能文件夹复制到项目的 `.claude/skills/` 目录下，或个人级的 `~/.claude/skills/`。之后描述你的任务，助手会自动匹配并按流程执行。

**其他工具**：每个 `SKILL.md` 都是纯 Markdown，直接作为提示词上下文喂进去同样有效。

## 关于真实性

课件里的每个版本号、每段终端输出、每张截图，都来自一台 Mac mini（M4 / macOS 26.4.1 / arm64）上的真实执行，不是示意图。因此你按步骤操作时看到的结果，应当与课件一致。

若某个命令因上游版本更新而失效，以官方最新文档为准——课件中标注了各处的版本前提。

# Personal Study Database

**[中文](./README.md) | English**

A personal archive of university lab reports, tool notes, and learning materials. Topics include LLM deployment and applications, DeepSeek Harness, LangChain, operating systems, and data fundamentals.

## About this repository

This repository collects lab reports, practical guides, and course notes, with a focus on deploying and applying large language models. It also contains selected coursework materials.

The project is hosted on **GitHub**. A related Gitee repository has similar content; choose whichever platform is more convenient.

## Contents

### Lab reports

- Environment setup and configuration
- Common Git commands
- LLM deployment and application experiments
- Rocky Linux fundamentals
- DeepSeek Harness integration and troubleshooting

### Tool and reading notes

- DeepSeek Harness document-operation walkthrough
- Dataset and AI notes

### Projects and diagrams

- **LangChain agent development:** Agent-Skills, RAG, Langfuse, and related exercises
- **Claude Code diagrams:** usage guides, flowcharts, and mind maps

The English index intentionally describes materials by topic rather than repeating student names or identifiers that appear in some archived filenames.

## Use

Browse or download files from GitHub, or clone the repository:

~~~bash
git clone https://github.com/liuzhiqiang23/personal-database-in-school-about-study.git
~~~

To contribute your own changes, create a branch, commit only the intended files, and push your branch.
